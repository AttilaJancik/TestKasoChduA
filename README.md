# TestKasoChduA

A short example of communication with Kverkom for the Kaso CHDU device

## Features

- initialize device with tester parameters
- communication with tax office server
- console informations of input and output data

## Requirements

installed .NET 4.7.2 SDK or later or .NET Core 3.1 SDK or later
installed Kaso Technologies CHDU software (version 2.0.9.1 or later)

## Installation

clone this project and compile for use

## Usage

1. set actual data for variables: **taxisKverkomSettings** , **taxisDrvAPI.Init** , **taxisQrKodPlatbyParams**
2. if need tracking of server, set variable: **lastQrId**
3. set variable **runFunction** for run selected function
4. push *Start without debugging* in IDE (VS-26)
